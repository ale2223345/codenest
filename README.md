# CodeNest — Sitio web institucional (Sprint II)

> **"Tu primer paso, escrito en código."**
> Academia de formación práctica en programación para Centroamérica.

Proyecto de la **Fase 2 (Sprint II) – Desarrollo Front-End**.
Universidad Don Bosco · LME901 – Lenguajes de Marcado y Estilo Web · Grupo 2.

## Tecnologías
- HTML5 semántico (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`)
- CSS3 (variables, gradientes, diseño consistente con el Manual de Marca)
- Bootstrap 5.3 y Bootstrap Icons
- JavaScript (comportamientos de navegación, formularios y alertas)

## Estructura del proyecto
```
CodeNest/
├── index.html        Inicio (hero, video, cursos, carrusel de testimonios)
├── nosotros.html     Historia, misión, visión y valores
├── servicios.html    Cursos, tabla comparativa, galería y video
├── faq.html          Preguntas frecuentes (acordeón)
├── blog.html         Artículos (modales) y boletín
├── contacto.html     Formulario, alertas y mapa
├── css/style.css     Estilos e identidad visual
├── js/main.js        Scripts del sitio
├── img/              Logotipos e imágenes institucionales
└── media/            Video institucional y póster
```

## Cómo ejecutarlo
No requiere instalación. Abre `index.html` en el navegador (se necesita conexión a internet para cargar Bootstrap y Google Fonts desde su CDN).
